# 🎨 Color Palette Generator

A single-page web application that allows users to generate and view beautiful color palettes based on their initial color selections.

🌐 **Live Demo**: [Color Palette Generator](https://tourmaline-centaur-1485f6.netlify.app/)

## 🚀 Features

- Select initial base colors using a color picker.
- Generate a cohesive color palette from the selected base colors.
- View each color as a visual swatch along with its Hex code.
- Click to **copy** any Hex code to the clipboard.
- Clean, minimal, and responsive design.

## 🛠️ Tech Stack

- **Frontend Framework**: React.js
- **Styling**: CSS
- **Deployment**: Netlify


## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/your-username/color-palette-generator.git

# Navigate to the project directory
cd color-palette-generator

# Install dependencies
npm install

# Run the development server
npm run dev
